# Правила для AI-агента: серия статей об ИИ

## Типографический шаблон серии

Все статьи этой серии должны использовать единый веб-шаблон первой публикации — `От_агента_к_смыслу_полная_WEB_версия_v2.html`.

- Перед изменением или созданием новой статьи извлекай CSS из первой статьи и используй его как базовый, а не как приблизительный референс.
- Сохраняй одинаковые: палитру, ширину страницы `1180px`, ширину колонки чтения `860px`, типографику, hero-блок, цитаты, код, иллюстрации и мобильную версию.
- Дополнительные элементы допустимы только как минимальные расширения и не должны менять базовую композицию или типографический характер первой статьи.
- Не заменяй и не удаляй исходную версию CSS первой статьи. Новые версии статьи сохраняй отдельно и нумеруй.

## Контент

- Оригинальные тексты статьи не редактируются без создания новой версии.
- Инженерные иллюстрации используют класс `board` внутри `section` и ширину колонки чтения.
